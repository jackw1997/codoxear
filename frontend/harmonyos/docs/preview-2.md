# HarmonyOS 第二版试用说明 · 2026-10-02

这是可试用的开发版本，尚未完成全部功能和视觉对齐。界面使用原生 ArkUI，没有 ArkWeb；截图来自已登录的开发模拟器。

## 本版增加与修复

- 帮助页面补齐九个章节；普通对话框支持按钮字母快捷键，文件链接支持屏幕内的键盘提示。
- 大文件编辑的撤销历史计算得到优化；1.212 MB 文件的连续输入、撤销重做、进程重启恢复和保存经过实际界面验证。
- 附件上传失败保留草稿；服务器已接收但响应丢失时，从服务器恢复附件状态；切换会话后的旧错误不再污染新会话。
- 修复后台优先级/统计刷新导致侧栏快捷键提示和滑动操作被重建的问题。
- 调整侧栏宽度、品牌图标、模型/后端/时间信息、分组计数和底部按钮；增加忙碌状态动画。
- 增加原生 PushKit 客户端与服务端接口。系统通知点击后冷启动、登录并定位原会话已经验证；华为实际后台推送尚未验证。

## 仍未完成

- 网页与原生界面尚未达到 1:1：字体度量、行内代码、复杂引用/列表、长表格和输入框细节仍有差异。
- 原生编辑器、PDF、媒体及自定义样式与网页版仍有交互和格式边界差异；并非 Monaco 或任意 CSS 的完整替代。
- 队列发送中状态、附件注入失败、无人值守冷却及错误、部分启动与断线边界还需补测。
- 系统“关闭过渡动画”在当前模拟器上未让侧栏状态点停止动画。应用调用的减少动画接口仍返回 false；这项兼容性问题未解决。
- 真实 TTS 语音、华为后台推送、真机折叠/旋转体验、手机签名与发布安装仍待验证或配置。
