The current conversation requires a self-contained Linux TypeScript migration with native PTYs, independent Computer/Hub/Client components, usable mobile browser flows, and preservation of existing v2 functions and the user's running legacy agents. Earlier designs remain useful evidence, but their superseded implementation prescriptions do not override these requirements. This audit records the decisions before the next implementation slices; it does not claim those slices have already passed acceptance.

The 6 October continuation expands the request to finish the outstanding register. Engineering work continues with GPT-6.1-Sol subagents. The web report at `progress.html` presents the current registers without requiring a Markdown reader. Live service and physical-device acceptance still require actual configured resources; an unresolved resource is not recorded as a passed test. Earlier clarification covered future-stage iOS/Android/OAR work and SDK/device/vendor resources. R45 now resolves OAR as the accepted refactor direction; platform/device gates remain separate.

## Corrected acceptance interpretation

The current records accept a Linux native TypeScript migration, not the complete design. They report a fresh v2-only production build, 160/160 Docker TypeScript tests without skips and 46 generic browser checks, together with additional targeted installed-CLI/provider/workspace evidence. Each remains subject to the precise evidence scope in the registers.
